# 图谱交互修复方案

## 目标

恢复旧版黑金视觉基调，并把族谱图从“图数据库关系展示”调整为“传统家谱树展示”。

## 当前问题

- 家庭单元节点被直接渲染成黄色中间点，暴露了后端图模型的实现细节。
- 人物卡片信息过多，年份会让节点显得拥挤。
- 连线使用通用图布局的折线/多段线，视觉上不够像家谱。
- 拖拽目前偏静态，需要更像图数据库视图的整体弹性移动。

## 修复方向

- 隐藏家庭单元节点，只保留人物方块。
- 人物方块只显示姓名，不显示出生/死亡年份。
- 家谱主视图使用横平竖直的树状连线，尽量贴近参考图二。
- 配偶使用同层水平线连接，子女从父母连线的中心向下分叉。
- 保留深色背景和金色强调，但降低线条干扰，让结构更清楚。
- 增加整体可拖拽视图，并在拖拽释放时加入轻微惯性/弹性反馈。

## 实施顺序

1. 提交当前已完成的登录、暗色 UI、后端图谱接口稳定性修复。
2. 改前端布局转换，过滤或折叠家庭单元节点。
3. 改 G6 渲染为更接近家谱树的节点和连线。
4. 调整拖拽体验，优先保证整体画布拖拽顺滑。
5. 跑前端测试、构建和后端测试。
