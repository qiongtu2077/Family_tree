# 前端测试计划

## 1. 当前收敛结论

旧方案文档已经归档到 `方案/已完成/`。当前测试工作只围绕一个最终口径展开：

- 前端正式图谱入口是五图：本家主线、姻亲谱系、联姻桥接、后代分支、家族全景。
- 关系路径是全局工具面板，不作为五图之一。
- 中心相关图必须先确定中心人物或根对象。
- 正式家谱图优先使用 `Person -> FamilyUnit -> Person` 投影；`PARENT_OF`、`SPOUSE_OF` 只作为查询、迁移或兜底兼容。
- 前端自动化测试由 `front/vitest.config.js` 收集 `front/src/tests/**/*.test.js`，新增测试目录是 `front/src/tests/测试/`。

## 2. 执行命令

普通前端单元测试和构建不需要 Python 环境。

```powershell
cd front
npm run test
npm run build
```

如果后续要跑后端 `pytest`，必须先进入项目 Conda 环境：

```powershell
conda activate familytree
cd after
pytest
```

浏览器 E2E 视觉巡检需要本地服务和 PostgreSQL 已启动。后端启动必须使用 `familytree` 环境：

```powershell
conda activate familytree
cd after
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

前端启动：

```powershell
cd front
npm run dev -- --host 127.0.0.1
```

执行真实浏览器视觉巡检：

```powershell
cd front
npm run test:e2e:visual
```

## 3. 可视化产物

新增测试会在运行时生成：

```text
front/src/tests/测试/artifacts/graph-layout-preview.html
```

打开这个 HTML 可以直接看到测试样例中的前端图谱长什么样，包括人物节点、配偶线、亲子线和折叠分支胶囊。

浏览器 E2E 会生成真实页面截图、画布截图和 JSON 报告：

```text
front/e2e/artifacts/visual-graph-audit/
front/e2e/artifacts/visual-graph-audit/report.json
```

报告中 `findings` 必须为空；否则说明当前页面、接口、图谱布局或画布渲染存在需要修复的问题。

## 4. MC/DC 覆盖原则

MC/DC 要求每个关键布尔条件都能独立影响判定结果。前端测试按“判定点 -> 条件 -> 正反用例 -> 预期影响”组织。

### 4.1 图谱布局 MC/DC

| 判定点 | 条件 | True 用例 | False 用例 | 验证目标 |
| --- | --- | --- | --- | --- |
| `layoutGraph` 视图选择 | `view_mode === overview` | `overview` | `mainline` | 全景图显示全部人物且不画正式家谱线；主线图生成亲子线 |
| 姻亲图入口 | `spouse_id && center_person_id && 两者存在` | 完整姻亲上下文 | 缺少 `spouse_id` | 完整上下文按配偶原生家庭布局；缺参时回退且不中断 |
| 桥接图入口 | `view_context.family_unit_id` 命中 | 多家庭中指定家庭 | 不指定家庭 | 指定家庭决定中间婚姻桥，非目标家庭不被误画 |
| 直接亲子兜底 | `child` 是否已有 `FamilyUnit` | 无家庭单元，仅 `PARENT_OF` | 已有 `FamilyUnit` 且有 `PARENT_OF` | 无家庭单元时生成兜底线；已有家庭单元时不生成重复兜底线 |
| 子女分支线 | `children.length > 1` | 两个子女 | 一个子女 | 多子女出现水平兄弟线；单子女不生成假分支线 |
| 折叠胶囊 | `branchCapsule` 或未放置人物存在 | 有折叠分支 | 无折叠分支 | 胶囊作为语义入口，不参与亲子连线 |

对应文件：

```text
front/src/tests/测试/mcdcGraphLayout.test.js
```

### 4.2 图谱数据 MC/DC

| 判定点 | 条件 | True 用例 | False 用例 | 验证目标 |
| --- | --- | --- | --- | --- |
| 中心人物搜索 | `keyword.trim()` 非空 | 输入姓名 | 空白输入 | 空白不请求接口，非空请求候选人物 |
| 中心候选兜底 | 图谱候选接口成功 | `getCenterCandidates` 成功 | 接口失败 | 成功时使用图谱候选；失败时退回普通人物搜索 |
| 分支加载 | `rootType === "familyUnit"` | `familyUnit` | `person` | 家庭单元走兼容接口并去掉 `family:` 前缀；人物走根节点接口 |
| 中心 ID 解析 | `view_context.center_person_id` 是否存在 | 姻亲图返回上下文中心 | 仅顶层 `center_person_id` | 上下文中心优先，保证切换视图不丢原中心 |
| 空图处理 | `nodes` 是否可渲染 | 有人物节点 | 无 `nodes` 或空数组 | 空图不造本地假数据，进入错误态 |
| 错误信息 | `response.data.detail` 是否存在 | FastAPI 错误 | 普通 Error | 优先展示接口详情，否则展示 JS 错误信息 |

对应文件：

```text
front/src/tests/测试/mcdcGraphData.test.js
```

### 4.3 浏览器视觉 E2E 覆盖

浏览器 E2E 不替代 MC/DC 单元测试，它验证“真实页面能不能被用户看到并操作”。用例由当前数据库和后端上下文动态生成。

| 覆盖点 | 数据来源 | 自动操作 | 自动判定 |
| --- | --- | --- | --- |
| 中心人物选择 | `/api/graph/center-candidates` | 搜索并选择 `张明远` | 主线图出现且画布非空 |
| 本家主线 | `/api/graph/mainline/{person_id}` | 点击“本家主线” | 无错误卡、非空 canvas、有接口节点和布局节点 |
| 姻亲谱系 | `/api/graph/center-context/{person_id}` 的 `available_spouses` | 枚举每个配偶选项 | 图谱模式为 `inlaw`，画布像素非空 |
| 联姻桥接 | 同一个配偶选项 | 枚举每个配偶并进入桥接图 | 图谱模式为 `bridge`，画布像素非空 |
| 后代分支 | `available_family_units` | 枚举每个家庭单元 | 图谱模式为 `branch`，画布像素非空 |
| 折叠胶囊 | 当前 G6 布局中的 `branchCapsule` | 逐个进入可跳转胶囊 | 目标图谱模式正确，截图保存 |
| 家族全景 | `/api/graph/overview` | 进入全部全景和中心九族 | 图谱模式为 `overview`，画布非空 |
| 关系路径 | 演示数据人物 ID | 查询 `demo:child` 到 `demo:grandfather` | 结果显示路径节点统计 |

对应文件：

```text
front/e2e/visualGraphAudit.mjs
```

最新一次通过时覆盖统计：

```text
spouseOptionCount = 1
familyOptionCount = 1
capsuleCount = 6
screenshotCount = 13
auditCaseCount = 12
findings = []
```

## 5. 验收标准

- `npm run test` 通过。
- `npm run build` 通过。
- `npm run test:e2e:visual` 通过。
- 新增测试目录能被 Vitest 自动发现，不需要手动指定文件。
- `graph-layout-preview.html` 可以打开并看到图谱。
- `visual-graph-audit/report.json` 中 `findings` 为空。
- 家族全景测试不复用主线布局。
- 正式家谱图不输出 `polyline`。
- 单子女家庭没有水平假分支线。
- 多子女家庭有兄弟水平分支线。
- `FamilyUnit` 不渲染成人物节点。
- 空图和接口失败不会生成本地虚假族谱。

## PostgreSQL 迁移后的验证

后端新增真实 SQLAlchemy Session 测试，覆盖五图、路径、人物 CRUD、家庭关系派生、生养关系并存、删除外键、账号绑定、迁移回滚和序列。默认使用开启外键的内存 SQLite；设置 `TEST_DATABASE_URL` 为 PostgreSQL URL 后，仓库测试会为每个用例创建独立随机 schema，结束后清理该 schema，不覆盖实际族谱表。

```powershell
conda activate familytree
cd after
$env:TEST_DATABASE_URL = 'postgresql+psycopg://<user>:<url-encoded-password>@127.0.0.1:5432/<database>'
python -m pytest
```

使用已迁移数据做只读页面巡检时，在 `front` 目录执行：

```powershell
$env:FAMILYTREE_E2E_PREPARE_DATA = '0'
npm run test:e2e:visual
```

该开关跳过账号和演示族谱初始化。折叠入口巡检先关闭遮挡画布的人物详情侧栏，再真实点击画布；不再使用调试句柄替代点击。数据库迁移验收还需比对源快照的全部人物属性、家庭属性、关系数量、账号 ID、密码哈希及人物绑定。默认快照和本地配置备份保存在未跟踪的 `.runtime/postgres-migration/`。
