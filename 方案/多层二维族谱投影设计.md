# 多层二维族谱投影设计

## 1. 问题结论

族谱数据本质上不是普通二维树，而是带有血缘、婚姻、姻亲、旁支、跨家族桥接的多关系图。如果把所有 `PARENT_OF`、`SPOUSE_OF`、`PARTNER_IN`、`HAS_CHILD` 同时画进一张平面图，就会出现三类问题：

- 线条跨层交叉：配偶原生家族、祖先兄妹家族、后代家族都在抢同一张二维平面。
- 语义层混淆：同一条亲子关系既可能来自 `FamilyUnit -> HAS_CHILD`，又可能来自 `Person -> PARENT_OF`，重复绘制后像线接错。
- 全景不可读：全景图如果默认画所有边，只能变成关系网毛线团，不能承担传统族谱阅读功能。

因此，五图设计必须把完整三维关系图投影成多个二维层。数据库保留完整关系，前端每次只展示当前视图需要的层，其它层折叠成入口、摘要或索引。

## 2. 总体规则

正式族谱图只使用 `FamilyUnit` 作为布局语义源：

```text
Person --PARTNER_IN--> FamilyUnit --HAS_CHILD--> Person
```

`PARENT_OF` 和 `SPOUSE_OF` 是查询和路径辅助关系，不作为正式家谱线的首选绘制依据。当同一关系已经存在家庭单元时，前端必须忽略冗余直连边，避免重复线。

正式族谱图只允许四类线段：

```text
夫妻线：水平线
父母下行线：垂直线
兄弟分支线：水平线，仅多子女时出现
子女上接线：垂直线
```

单子女家庭不画兄弟分支线，只画父母中心到子女上边的直线。这样不会在单子女下方生成没有意义的拐点。

## 3. 五图职责

### 3.1 本家主线

本家主线回答“中心人物在本家血缘链上的位置”。它只展开中心人物向上的父母家庭和向下的子女家庭。

布局规则：

- 中心人物作为主线锚点。
- 向上只走 `parentFamiliesByChild` 的第一条稳定父母家庭。
- 向下只展开中心人物和后代作为伴侣进入的子女家庭。
- 已婚子女作为上层家庭子女时，本人必须对齐父母下行线，配偶放侧边。
- 配偶的原生父母和兄妹不在本图展开，只能通过姻亲谱系或联姻桥接查看。

### 3.2 姻亲谱系

姻亲谱系回答“配偶原生家族是什么样”。它以选中的配偶为中心，复用主线投影规则，但中心换成配偶。

布局规则：

- 只展示配偶自己的父母、祖先、兄妹和后代。
- 当前本家人物只作为配偶关系的一端出现，不展开其本家祖先。
- 跨家族内容不在本图继续展开，避免两个家族平面互相穿线。

### 3.3 联姻桥接

联姻桥接回答“两边家族如何通过婚姻连接”。它不是全量家谱，而是两个局部树加中间婚姻带。

布局规则：

- 中央放选中婚姻家庭，夫妻线水平。
- 左右两侧分别向上展示双方近祖先。
- 共同子女放在婚姻家庭下方。
- 双方远亲和旁支默认折叠，不跨越中央区域拉长线。
- 桥接图只解释连接关系，不承担全家族浏览任务。

### 3.4 后代分支

后代分支回答“某个祖先或家庭单元往下有哪些后代”。它必须从一个家庭单元向下递归，而不是从一个人物沿所有关系乱走。

后端投影规则：

```text
root FamilyUnit
  -> HAS_CHILD children
  -> children 的 PARTNER_IN 家庭单元
  -> 下一代 HAS_CHILD
```

禁止：

- 禁止 `HAS_CHILD|PARENT_OF*` 混合可变路径。
- 禁止把祖先兄妹、姻亲远支和路径辅助边加入分支主图。
- 禁止在一个大 Cypher 里混合 `root` 与聚合列导致 Neo4j 隐式分组错误。

前端入口规则：

- 如果当前人物有自己的子女家庭，优先以该家庭作为根。
- 如果当前人物没有后代，回退到当前主线中能覆盖他的最上层祖先家庭。
- 如果仍找不到家庭单元，才显示人物自身并提示暂无后代。

### 3.5 家族全景

家族全景回答“系统里有哪些人、有哪些家庭簇”。它不是传统族谱阅读图，而是管理员和浏览者的索引地图。

布局规则：

- 所有返回人物必须可见。
- `FamilyUnit` 不渲染成可见节点。
- 默认按家庭单元分簇，人物以小卡片排列。
- 默认不画全量亲缘线，避免全景图变成毛线团。
- 查看具体关系时切换到本家主线、姻亲谱系、联姻桥接或后代分支。

## 4. 为什么这是“三维变二维”

完整族谱可以理解成三维结构：

```text
Z 轴：关系语义层
  血缘层
  婚姻层
  姻亲层
  旁支层
  管理诊断层

X 轴：同代横向顺序
Y 轴：代际上下顺序
```

二维屏幕只能稳定表达 X/Y 两个轴，所以每张图只能选择一个主要 Z 层。其它 Z 层必须折叠，否则就会出现交叉线、重合线和无法解释的拐点。

五图就是五次不同的 Z 层切片：

- 本家主线：血缘主层。
- 姻亲谱系：配偶血缘层。
- 联姻桥接：婚姻连接层。
- 后代分支：单根后代层。
- 家族全景：索引管理层。

## 5. 验收标准

- 后代分支接口不再 500。
- 切换后代分支时，默认示例不应只剩一个无后代人物。
- 全景图能显示全部人物，但默认不画密集交叉边。
- 单子女家庭没有横向假分支线。
- 多子女家庭才出现兄弟水平分支线。
- 正式家谱图没有自动 `polyline`。
- 人物框只显示姓名，不显示年份。
- 选中态只高亮边框，不填满整块。
