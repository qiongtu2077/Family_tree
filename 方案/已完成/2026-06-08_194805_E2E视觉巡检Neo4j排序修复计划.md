## 2. 原始错误

执行命令：

```powershell
cd front
npm run test:e2e:visual
```

E2E 截图和 `report.json` 记录到的后端错误：

```text
Neo4j 服务不可用: {code: Neo.ClientError.Statement.SyntaxError}
In a WITH/RETURN with DISTINCT or an aggregation, it is not possible to access variables declared before the WITH/RETURN: unit
"        ORDER BY unit.displayOrder, unit.familyUnitId"
```

继续修复后又暴露同类错误：

```text
Neo4j 服务不可用: {code: Neo.ClientError.Statement.SyntaxError}
In a WITH/RETURN with DISTINCT or an aggregation, it is not possible to access variables declared before the WITH/RETURN: partner
"        ORDER BY partner.birthDate, partner.name, partner.personId"
```

## 3. 原因定位

已确认：根因是 Neo4j 5 对 `WITH/RETURN DISTINCT` 后的作用域更严格。

旧查询在 `RETURN DISTINCT unit.familyUnitId AS family_unit_id` 或 `RETURN DISTINCT partner.personId AS person_id` 后，继续 `ORDER BY unit.displayOrder` 或 `ORDER BY partner.birthDate`。此时 `unit`、`partner` 节点变量没有被保留在返回投影里，因此 Neo4j 拒绝执行。

影响文件：

```text
after/app/repositories/graph_repository.py
```

影响路径：

- 本家主线图
- 姻亲谱系图
- 联姻桥接图
- 后代分支图中部分家庭单元查询
- 家族全景图中人物触达家庭单元查询

## 4. 修复内容

已将同类查询改为先保留节点变量去重，再返回字段并排序：

```cypher
WITH DISTINCT unit
RETURN unit.familyUnitId AS family_unit_id
ORDER BY unit.displayOrder, unit.familyUnitId
```

以及：

```cypher
WITH DISTINCT partner
RETURN partner.personId AS person_id
ORDER BY partner.birthDate, partner.name, partner.personId
```
