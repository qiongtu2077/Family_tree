## 3. 失败现象

执行命令：

```powershell
cd front
npm run test:e2e:visual
```

失败位置：

```text
getByRole('button', { name: '本家主线' }).click()
```

原始错误要点：

```text
<button class="primary-btn">搜索</button> intercepts pointer events
```

中文含义：

```text
浏览器尝试点击“本家主线”视图按钮时，工具栏里的“搜索”按钮覆盖在点击位置上，拦截了鼠标事件。
```

## 4. 原因定位

已确认：这是前端工具栏布局遮挡问题，不是后端数据问题，也不是 Neo4j 初始化问题。

相关文件：

```text
front/src/components/graph/GraphToolbar.vue
```

当前工具栏使用四列 grid：

```css
grid-template-columns: auto minmax(260px, 420px) 1fr auto;
```

当视图按钮和操作按钮总宽度较大时，中间列发生挤压，搜索按钮会覆盖视图 tab 区域，导致自动化浏览器和真实用户点击都存在风险。

## 5. 修复计划

1. 修改 `GraphToolbar.vue` 的 grid 布局。
   - 将工具栏改成可换行布局。
   - 保证搜索区、视图 tab、右侧操作区不会互相覆盖。
   - 保留当前黑金视觉样式。

2. 为 `view-tabs` 与 `toolbar-actions` 增加 `min-width: 0` 和 `flex-wrap`。
   - 中等宽度下按钮自动换行。
   - 不允许按钮层叠遮挡。

3. 重新执行：

```powershell
cd front
npm run test:e2e:visual
npm run test
npm run build
```

4. 调整 E2E 默认中心人物。
   - 原默认人物 `张一宁` 是子女节点，没有配偶/伴侣家庭。
   - 姻亲谱系和联姻桥接按业务规则需要明确配偶，因此使用 `张一宁` 无法覆盖所有分支。
   - 将默认中心人物改为 `张明远`，该人物在演示数据中有配偶、子女和父母家庭，能覆盖本家主线、姻亲、桥接、后代分支、全景和关系路径。
